How the checks were run. The author ran the checks with AI-assisted verification. AI models compared each filed estimate with the paper it cites, and the author reviewed the results and applied the corrections. The method and its limits are in the framework.

How this log is made. A script reads the published page of every release and compares it with the release before. It writes one row for each field that changed on each link, and one row for each link added or removed. The reason comes from the reviewer’s note on the link, the correction record in the dataset repository, and (from version 2.0) the grade basis. Where none is recorded, the row shows the release message. Rule ids such as T3 or C1 refer to the decision table in the framework.

Reading the grades. Before version 2.0 the grades were called Convincing, Probable, Suggestive, Limited and Contested. They are now Strong, Moderate, Suggestive, Weak and Conflicting. The log lists a grade change only when the level moved. Translated texts are left out. Each link has an anchor: changelog.html#risk|disease.

Version 2.0 is not published yet. It renames the grades, adds the related-outcome layer and applies the counting rule. The version 2.0 rows are added to this log when it is published.

The stated 1.35 (1.22-1.49) for current versus never smokers, graded 'Probable', is contradicted by the largest pooled observational analysis available (231,020 participants across 22 population studies), which found exactly no association (OR 1.00, 0.91-1.09).
